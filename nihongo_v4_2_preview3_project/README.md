## 開啟

解壓縮後，用 Chrome 或 Edge 開啟 `index.html`。資料、樣式、程式均已封裝在 HTML，沒有外部網路依賴。另附的單檔 HTML 與此檔相同。離線實際開啟、手機視窗與 Android 實機仍待測，不能把封裝檢查當作瀏覽器測試。

## 先備份再換版

舊版 V3 的「題庫管理 → 備份題庫與學習紀錄」可下載完整備份；舊版 V2 可在「學習分析」匯出學習紀錄。開啟新版後，至「題庫管理 → 還原備份」載入。

不同檔案路徑、瀏覽器或網址可能有不同的 localStorage，請勿假設新版會自動看到舊版資料。在同一儲存空間可讀到舊資料時，程式會先保存原始備份再升級，舊鍵不會刪除。損壞資料會停止寫入並顯示提示；「保留原始儲存資料」可下載診斷備份，但該原始備份不是一般學習還原格式。

- 保留平／片假名、原 97 題、V3 新增的 25 題，合計 122 題示範試做。
- 保留分類、隨機／未作答／錯題／弱點練習、即時批改與繁體中文解析。
- 暫停續練、作答題目快照、原版本保留、課程完成條件與簡化間隔複習。
- N5 三課：自我介紹與所屬、場所與同行者、短文與生活公告。課程內容透過 ID 關聯既有示範題。
- 補充濁音、半濁音、拗音、促音／長音／撥音說明與字卡，提供不計統計的拼音輸入示範。
- JSON 檢查預覽、完整匯出、版本更新、備份合併還原、錯誤及容量失敗提示。

## 題庫與審核

共 192 題，含 92 題假名與 100 題 N5 候選。N5 分布：單字 35、文法 35、閱讀 20、聽力草稿 10。全部尚未經獨立人工審核，正式發布 0 題。新候選題不會進入練習；無音檔聽力也不可試做。原 V3 題目以 `legacyDemo` 明確保留示範用途。

題庫使用 schemaVersion 2。ID 穩定；同 ID 同內容重匯會略過；更新內容必須提高 version，舊版會保存於 history。既有作答若有 snapshot，顯示作答當時的題目與解析。V2／V3 舊紀錄未保存快照者不會被偽造補上。

發布流程：draft → pending_review → approved → published；disabled 可停用。核准／發布必須有該版本人工審核紀錄及確認授權。`reviewRecords` 的 `type=human`、`version`、`reviewer`、`at`、`japanese`、`uniqueAnswer`、`traditionalChinese` 須完整；AI 自查不符合條件。離線管理無法驗證審核者身分，這不是正式後台權限機制。聽力播放引擎尚未開放，即使匯入音檔資料也不會當成可練習題。

高相似度檢查使用字元二連組 Jaccard，門檻 72%；只是提示，不會自動刪題或取代語意審核。見 `CONTENT_REVIEW.md`。

## 開發與驗證

需要現有 Node.js，無第三方套件：

```text
node tools/build.cjs
node tests/run.cjs
node tests/management.cjs
node tests/stability.cjs
node tests/learning.cjs
node tools/validate.cjs
```

日常新增內容修改 `data/question-bank.json` 或 `data/courses.json`，再建置，不用改 HTML 或課程引擎。`source/v3-compat.js` 保留舊版正常功能；只在相關修復時修改。`prepare-content.cjs` 與 `extract-compat.cjs` 是一次性來源建立工具，不屬於日常流程，請勿用它們覆蓋後續編輯的資料或程式。

建置後再執行 `node tools/build-browser-check.cjs` 更新瀏覽器驗收頁；`npm run build`會依序執行兩者。`node tools/preview.cjs`啟動本機HTTP預覽，環境允許時可開啟 `/browser-acceptance.html`。該頁以隨機鍵前綴隔離真實DOM／儲存測試，可下載結果；本交付尚未執行，不能當作已驗收證據。原生檔案操作、真正關閉瀏覽器與實機仍需另驗收。

測試輸出寫入 `test-results/`，不納入 Git。通過項目及限制見 `TEST_SUMMARY.md`。Git 基線保留於 `previous/nihongo_v3.html`；原交付 HTML／ZIP 也未覆寫。附帶 Git bundle 可用 `git clone nihongo-history.bundle restored-project` 還原提交歷史。
